## Credits 与 Evidence <Status level="not_yet_wired" />

<Warning>
**这些端点在线并返回 `200`，但背后什么都没接。**

`GET /v1/operator/me/credits` 返回的 `settled`、`pending`、`estimated` 全是 `0`，
并附带 `"source": "not_yet_wired"`。

**这个零是占位符，不是测量结果**——它的意思是"还没有任何东西在计数"，
而不是"你没有赚到任何东西"。这是两句完全不同的话。

如果你要展示这些数字，就必须把说明一起展示。SDK 强制执行这一点：`settledCredits()`
会抛异常，而不是把一个可能被当成余额显示的零交给你。想展示时请用 `creditsRaw()`。
</Warning>

**Credits 是测试单位。** 不是现金，不可兑换，不代表对未来价值的任何主张。

</Note>

## 没有做的 <Status level="planned" />

没有代码，没有端点，没有东西可调用。列在这里是为了让你看清网络的意图，**不是**为了让你
基于它开发。

| 领域 | 状态 |

<Warning>
**这套 API 里没有任何一个端点会转移价值。** 没有钱包，没有 swap，没有质押，没有代币转账，
没有交易。这是刻意的范围决策。如果你发现哪个页面暗示了相反的意思，那是 bug，
请[报告](/community)。
</Warning>

## 自己核实

不必相信这一页。

```bash
curl -s https://registry.libertynet.ai/health
curl -s https://registry.libertynet.ai/nodes | head -c 300
```

SDK 里有一个对着真实网络跑的测试，专门断言这一页仍然成立：

```bash
cd sdk/python && LN_LIVE=1 python3 -m pytest -q
```

只要真实注册表上有任何一个身份验证不通过，它就会失败——那意味着要么网络出了问题，
要么这份文档错了，两种都值得立刻知道。

## 状态什么时候会变

一个能力的标记，在**改变其行为的同一个提交里**改变，绝不提前。先宣布、后交付，正是
"规划中"在读者记忆里悄悄变成"已启用"的方式，这个项目不这么做。
