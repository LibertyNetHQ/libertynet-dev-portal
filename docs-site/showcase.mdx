## Get listed

If you build something — however small, however rough — it belongs here.

<Steps>
  <Step title="Open an issue">
    On [libertynet-dev-portal](https://github.com/LibertyNetHQ/libertynet-dev-portal/issues/new?labels=showcase&title=Showcase%3A+),
    labelled `showcase`.
  </Step>
  <Step title="Tell us four things">
    What it does in one sentence · which parts of LibertyNet it uses · a link if it is
    public · **what was harder than it should have been**.
  </Step>
  <Step title="That last one is the point">
    Friction you hit is friction everyone hits, and it usually means a documentation page is
    unclear rather than that you did something wrong. It is the most valuable thing you can
    send us.
  </Step>
</Steps>

<Note>
**Work in progress is welcome.** A half-finished agent that revealed a confusing error
message is more useful to this project than a polished one that went smoothly.
</Note>

## What will not appear here

- Projects that do not exist, described in the future tense.
- The maintainers' own work presented as community adoption.
- Anything implying LibertyNet has capabilities it does not —
  [see the matrix](/status).

When a real third-party project lands, this warning is replaced by that project, in the same
commit.
