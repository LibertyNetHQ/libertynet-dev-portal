Four steps. The first needs nothing but `curl`; the rest need only Node.js **or** Python, with no
packages to install. Every snippet on this page was run against the live network before it was
published, and the outputs shown are the real ones.

<Info>
**There is no signup step.** Discovery on LibertyNet is public. You are not waiting for a key,
because there is no key. If a page ever asks you to apply for one to read the network, that page
is wrong.
</Info>

<Warning>
**`status: "active"` does not mean online.** A node that stopped heart-beating stays in the table
with a stale `last_seen`. Freshness is your job — step 3 does it properly. Trusting the `status`
string is the single most common first mistake on this network.
</Warning>

## 3. Verify an identity yourself

This is the step that makes LibertyNet different, and it is worth the two minutes.

A LibertyNet DID is **self-certifying**: the identifier is derived from the public key. You can
confirm that a claimed identity really belongs to a claimed key using nothing but a SHA-256
implementation — no registry lookup, no certificate authority, no trusting the response you just
received.

Save this as `verify.mjs` (or `verify.py`) and run it. **No packages to install.**

<CodeGroup>

```typescript verify.mjs
import { createHash } from "node:crypto";

const B58 = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz";

function b58decode(s) {
  let n = 0n;
  for (const c of s) {
    const i = B58.indexOf(c);
    if (i < 0) return null;
    n = n * 58n + BigInt(i);
  }
  let hex = n.toString(16);
  if (hex.length % 2) hex = "0" + hex;
  // base58 drops leading zero bytes, so restore one per leading '1'
  let lead = 0;
  for (const c of s) { if (c === "1") lead++; else break; }
  return Buffer.concat([Buffer.alloc(lead), Buffer.from(hex, "hex")]);
}

// The registry serves keys as hex in /nodes and as base58 in /peers. Same key.
function keyBytes(pk) {
  return /^[0-9a-f]{64}$/.test(pk) ? Buffer.from(pk, "hex") : b58decode(pk);
}

/** Does this DID actually derive from this public key? */
function verifyIdBinding(did, publicKey) {
  const key = keyBytes(publicKey);
  if (!key || key.length !== 32) return false;

  const digest = createHash("sha256").update(key).digest("hex");
  const body = did.replace(/^did:svrp:(?:[a-z]:)?/, "");

  if (body.length === 64) return body === key.toString("hex"); // full-hex form
  if (body.length === 8) return body === digest.slice(0, 8);   // short form
  if (body.length === 10) return body === digest.slice(0, 10); // collision fallback
  return false;
}

const { nodes } = await (await fetch("https://registry.libertynet.ai/nodes")).json();

let verified = 0;
for (const n of nodes) {
  if (verifyIdBinding(n.did, n.public_key)) verified++;
  else console.log("REJECT", n.did);
}
console.log(`${verified}/${nodes.length} identities verified`);

const fresh = nodes.filter(
  (n) => n.last_seen && Date.now() - Date.parse(n.last_seen) < 10 * 60 * 1000,
);
console.log(`${fresh.length} seen in the last 10 minutes`);
```

```python verify.py
import hashlib, json, re, urllib.request

B58 = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz"

def b58decode(s):
    n = 0
    for c in s:
        i = B58.find(c)
        if i < 0:
            return None
        n = n * 58 + i
    raw = n.to_bytes((n.bit_length() + 7) // 8, "big")
    # base58 drops leading zero bytes, so restore one per leading '1'
    return b"\0" * (len(s) - len(s.lstrip("1"))) + raw

# The registry serves keys as hex in /nodes and as base58 in /peers. Same key.
def key_bytes(pk):
    if re.fullmatch(r"[0-9a-f]{64}", pk):
        return bytes.fromhex(pk)
    return b58decode(pk)

def verify_id_binding(did: str, public_key: str) -> bool:
    """Does this DID actually derive from this public key?"""
    key = key_bytes(public_key)
    if not key or len(key) != 32:
        return False

    digest = hashlib.sha256(key).hexdigest()
    body = re.sub(r"^did:svrp:(?:[a-z]:)?", "", did)

    if len(body) == 64:
        return body == key.hex()        # full-hex form
    if len(body) == 8:
        return body == digest[:8]       # short form
    if len(body) == 10:
        return body == digest[:10]      # collision fallback
    return False

with urllib.request.urlopen("https://registry.libertynet.ai/nodes", timeout=10) as r:
    nodes = json.load(r)["nodes"]

verified = sum(verify_id_binding(n["did"], n["public_key"]) for n in nodes)
print(f"{verified}/{len(nodes)} identities verified")
```

</CodeGroup>

```text Output — real run, 2026-07-31
27/27 identities verified
2 seen in the last 10 minutes
```

You just cryptographically checked every identity on the network without asking anyone's
permission. That is the whole point.

<Note>
**Why two DID encodings?** The same key appears as short `did:svrp:n:<8hex>` (a truncated SHA-256
of the key) and as full `did:svrp:<64hex>` (the key itself). Bindings are stored short; a running
daemon announces long. They are the same node. String comparison will lie to you here —
[DID reference](/reference/dids) has the details.
</Note>

## 4. Call a node, and check that it answered

Verifying an identity proves the DID matches the key. It does **not** prove anyone is home,
or that whoever answers holds the private key. This step does both.

<Warning>
**Most nodes on the network cannot be called by you.** Of 28 records right now, 4 advertise
RFC1918 addresses and 13 advertise `node://someones-laptop` labels — real to their operator,
unreachable from anywhere else. Ask the registry for the ones that are actually usable:

```bash
curl -s 'https://registry.libertynet.ai/nodes?callable=1'
```

That returns nodes which are **publicly reachable and carry a registration signature**.
Today that is a small number, and the SDKs default to exactly this set.
</Warning>

```python act.py
import json, urllib.request, hashlib, secrets

def post(url, data):
    req = urllib.request.Request(url, data=json.dumps(data).encode(),
                                 headers={"content-type": "application/json"}, method="POST")
    with urllib.request.urlopen(req, timeout=15) as r:
        return json.load(r)

# Only nodes you can actually reach.
with urllib.request.urlopen("https://registry.libertynet.ai/nodes?callable=1") as r:
    node = json.load(r)["nodes"][0]

# YOU choose the nonce. That is what makes the reply a proof rather than a recording:
# a signature over something we prepared earlier could just be replayed at you.
nonce = secrets.token_hex(8)
reply = post(node["endpoint"] + "/echo", {"nonce": nonce})

assert reply["nonce"] == nonce, "node echoed a different nonce"
assert reply["public_key"] == node["public_key"], "responder is not the node we discovered"

print("called   ", node["endpoint"])
print("signed   ", reply["signed_bytes"])
print("signature", reply["signature"][:32], "…")
```

Now verify that signature. Ed25519 needs a library — this is the one step in the quickstart
that does:

```bash
pip install cryptography
```

```python verify_reply.py
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

# b58decode and key_bytes from step 3
Ed25519PublicKey.from_public_bytes(key_bytes(reply["public_key"])).verify(
    b58decode(reply["signature"]),
    reply["signed_bytes"].encode(),
)
print("the node holds the private key for the identity you verified")
```

```text Real run
called    https://libertynet.ai/demo-node
signed    libertynet-demo-node-response:v1\n3f2a1c…\n1785561148
signature G7Y9CFkGBac8TamouNgJhz4vt9yPSouAPuMK2Dvi2EWw …
the node holds the private key for the identity you verified
```

That is the whole loop: you found a node, checked its identity against arithmetic, called it,
and confirmed the reply came from the key you checked. No account, no API key, nobody's
permission.

<Note>
**About the node you just called.** `did:svrp:n:dbe63a0c` at `https://libertynet.ai/demo-node`
is a canonical demo node run by the project. It exists so this page is true for people
outside it, and it deliberately holds nothing of value — its key signs its own registration
and these demo replies, nothing else.

It is not a special case: it registers, signs and heartbeats through exactly the same public
endpoints your node would. [Run your own](/guides/service-agent).
</Note>

<Warning>
**Never put a private key in a config file, a `.env`, or anywhere in a repository.**

Nothing in this quickstart needs one — discovery and verification are public, and the demo
node signs with its own key, not yours. When you do eventually hold a key (as an operator),
read it from your OS keychain or a secret manager at the point of use:

```python
import keyring
secret = bytes.fromhex(keyring.get_password("libertynet", "device-key"))
```

A key in a file is a key in your backups, your shell history and your crash dumps. There is
no reset flow on this network, because a reset flow is a second and weaker way in.
</Warning>

## 5. Do it in one line instead

Everything above is what the SDK does for you, with the verification non-optional.

<CodeGroup>

```typescript TypeScript
import { LibertyNet } from "libertynet-sdk";

const ln = new LibertyNet();                 // verification is on; you cannot turn it off
const nodes = await ln.discovery.callable(); // verified, fresh, reachable, signed

console.log(nodes.map((n) => `${n.did} ${n.endpoint} ${n.capabilities.join(",")}`));
```

```python Python
from libertynet import LibertyNet

ln = LibertyNet()                      # verification is on; you cannot turn it off
nodes = ln.discovery.callable_nodes()  # verified, fresh, reachable, signed

for n in nodes:
    print(n.did, n.endpoint, ",".join(n.capabilities))
```

</CodeGroup>

`online()` rejects any record whose identity does not verify, drops anything not seen
recently, and — since it would otherwise hand you addresses that can never answer — excludes
nodes you cannot reach. `callable()` additionally requires a registration signature.

There is no flag to disable identity verification. A client that trusts unverified identities
is not a client we are willing to ship.

<Note>
Expect small numbers. Right now `callable()` returns **1** of 28 records. That is a true
statement about the state of the network, not a bug in your code — and printing one address
that answers is more useful than printing 28 that time out.
</Note>

See [SDK overview](/sdk/overview) for installation, including how to run it from source today.
