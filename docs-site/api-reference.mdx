## Node discovery

**Base URL** `https://registry.libertynet.ai` · **Auth** none

### `GET /health` <Status level="implemented" />

Registry liveness

Registry liveness + registered node count.

```bash
curl -s https://registry.libertynet.ai/health
```

### `GET /nodes` <Status level="implemented" />

List all registered nodes

Full node table as JSON. Each record carries computed `reachability` (public|private|unroutable) and `signature_present`. Use `?callable=1` for only publicly-reachable, signed nodes — today that is 1 of 28.

```bash
curl -s https://registry.libertynet.ai/nodes
```

### `GET /peers` <Status level="implemented" />

List peers as plain text

Plain-text peer list (did pubkey endpoint per line), for shell tooling.

```bash
curl -s https://registry.libertynet.ai/peers
```

### `GET /api/v1/peers` <Status level="not_yet_wired" />

List peers (JSON envelope)

Returns 200 with a well-formed envelope, but the peer list inside is always empty — it is NOT the JSON form of /peers. Probed 2026-08-13: GET /peers returned 4+ real nodes with endpoints, while GET /api/v1/peers returned {"ok": true, "data": [], "error": null} at the same moment. Use /peers or /nodes until this is wired.

### `POST /api/v1/register` <Status level="implemented" />

Register a node

A node announces itself. Signature verification is enforced in grace mode.

### `POST /api/v1/heartbeat` <Status level="implemented" />

Refresh a node's last_seen

A node refreshes last_seen. Drives the `online` flag.

### `GET /nodes?callable=1` <Status level="implemented" />

Only nodes that are publicly reachable AND carry a registration signature. The honest answer to "who can I actually call".

```bash
curl -s https://registry.libertynet.ai/nodes?callable=1
```


## Node ↔ operator binding (double-signature)

**Base URL** `https://registry.libertynet.ai` · **Auth** ed25519 signatures; no API key

### `POST /v1/bindings/initiate` <Status level="implemented" />

Open a binding session (node side)

Node opens a binding session. Returns short_code + binding_token exactly once.

### `POST /v1/bindings/resolve` <Status level="implemented" />

Redeem a binding code (console side)

Console redeems the code/token and reads what the node is asking for.

### `POST /v1/bindings/authorize` <Status level="implemented" />

Authorize a binding (operator side)

Operator's device key signs an AuthorizationCredential.

### `GET /v1/bindings/{binding_session_id}/status` <Status level="implemented" />

Poll a binding session

Poll the session state machine.

### `POST /v1/bindings/{binding_session_id}/cancel` <Status level="implemented" />

Cancel a binding session

Abort a non-terminal session.

### `POST /v1/node/bindings/pending` <Status level="implemented" />

Poll for authorizations awaiting this node

Node polls for authorizations awaiting its acceptance. Signed poll.

### `POST /v1/node/bindings/{binding_session_id}/accept` <Status level="implemented" />

Accept a binding (node side)

Node accepts; registry re-verifies all four signatures before ACTIVE.

### `POST /v1/node/bindings/{binding_session_id}/reject` <Status level="implemented" />

Reject a binding (node side)

Node refuses the binding.

## Coordination — ask the network to do work

**Base URL** `https://libertynet.ai/coordination` · **Auth** ed25519 signed envelope on every call, reads included; no API key, nothing issued

### `GET /healthz` <Status level="implemented" />

Liveness probe

Gateway liveness. Unauthenticated on purpose, and rate limited by address like everything else.

```bash
curl -s https://libertynet.ai/coordination/healthz
```

### `GET /version` <Status level="implemented" />

Contract and build version

The contract version the gateway enforces and its own build version. Check this before blaming a signature: a client built against a different contract major fails as `signature_invalid`, which does not mention versions at all.

```bash
curl -s https://libertynet.ai/coordination/version
```

### `GET /openapi.json` <Status level="implemented" />

This document

The authoritative coordination contract, served by the process that enforces it. `api-spec/libertynet-v1.yaml` is generated from this, not the other way round.

```bash
curl -s https://libertynet.ai/coordination/openapi.json
```

### `GET /v1/capabilities` <Status level="implemented" />

Capability catalogue

What `capability_requirement.capability_type` may be set to. Guessing wrong used to fail later, at `get_proposal`, as "no capability passed qualification" — naming neither the field nor the mistake.

```bash
curl -s https://libertynet.ai/coordination/v1/capabilities
```

### `POST /v1/intents` <Status level="implemented" />

Submit an Intent

Opens a session. The envelope's signer must equal `intent.requester_did`. Submitting the same Intent twice returns the same session with `duplicate: true`, because the Intent id is derived from its content.

### `GET /v1/sessions/{session_id}` <Status level="implemented" />

Session status

Session state. Authenticated and bound to the session in the URL.

### `GET /v1/sessions/{session_id}/proposal` <Status level="implemented" />

Get the recommended proposal and its alternatives

The recommended proposal plus alternatives, with whether authorization is required.

### `POST /v1/sessions/{session_id}/commitment` <Status level="implemented" />

Prepare the draft Commitment for signing

Returns the draft Commitment to sign. The body is itself the signed envelope.

### `GET /v1/sessions/{session_id}/commitment` <Status level="implemented" />

Get the session's Commitment, if one exists

The session's Commitment once one exists.

### `POST /v1/sessions/{session_id}/authorize` <Status level="implemented" />

Authorize the proposal and start execution

Authorizes the proposal and runs the work. Blocks for as long as the delivery takes — set no client timeout.

### `POST /v1/sessions/{session_id}/cancel` <Status level="implemented" />

Cancel the session

Cancels a non-terminal session.

### `GET /v1/sessions/{session_id}/result` <Status level="implemented" />

Delivered result

The delivered result and its digest, once the session completes.

### `GET /v1/sessions/{session_id}/receipt` <Status level="implemented" />

Final receipt

The final receipt, including the settlement figure. **That figure is an accounting record and moves no value.** Fuel settlement is deliberately not wired on this deployment: no rate card is provisioned, so nothing is charged (deny-by-default).

### `GET /v1/sessions/{session_id}/events` <Status level="implemented" />

Session events (polling snapshot — NOT a push stream)

A polling snapshot of the session's events. It is **not** a push stream — no SSE, no websocket. Poll it.

### `POST /v1/objects` <Status level="implemented" />

Upload an input object

Upload an input object. The signature covers the digest of the bytes, so a captured upload envelope cannot be reused to store something else under your name.

### `GET /v1/objects/{object_id}` <Status level="implemented" />

Download an object

Download an object. Authenticated — an object id is derived from its content, so an unauthenticated read would serve any caller who could compute one.

### `POST /v1/runtimes` <Status level="implemented" />

Register an executable runtime package

Register an executable runtime package. Same digest-covering signature as object upload.


## Compute App — the first application on the coordination API

**Base URL** `https://libertynet.ai/compute` · **Auth** the caller's own ed25519 envelopes, forwarded unchanged; this service holds no key

### `GET /` <Status level="implemented" />

The browser UI. Submit -> Proposal -> Commitment -> Session -> Result -> Receipt, client-side hash routing.

```bash
curl -s https://libertynet.ai/compute/
```

### `GET /healthz` <Status level="implemented" />

Liveness probe

Liveness.

```bash
curl -s https://libertynet.ai/compute/healthz
```

### `GET /readyz` <Status level="implemented" />

Readiness, plus the platform gateway URL and contract version this build talks.

```bash
curl -s https://libertynet.ai/compute/readyz
```

### `GET /version` <Status level="implemented" />

Contract and build version

Service name, build version and the configured gateway.

```bash
curl -s https://libertynet.ai/compute/version
```

### `GET /openapi.json` <Status level="implemented" />

This document

This service's own contract — distinct from the platform's, which is at /coordination/openapi.json.

```bash
curl -s https://libertynet.ai/compute/openapi.json
```

### `GET /metrics` <Status level="implemented" />

Prometheus text exposition.

```bash
curl -s https://libertynet.ai/compute/metrics
```

### `GET /v1/task-package` <Status level="implemented" />

The WebAssembly task guest the browser registers before it can submit. A browser has no filesystem, so it fetches the bytes here and registers them with the platform itself.

```bash
curl -s https://libertynet.ai/compute/v1/task-package
```

### `POST /v1/derive-core-intent` <Status level="implemented" />

Turns a plain compute request into the exact platform Intent to sign, including the derived `intent_id`. Unsigned: it computes, it does not act.

### `POST /v1/intents` <Status level="implemented" />

Submit an Intent

Forwards the caller's signed `submit_intent` envelope to the platform unchanged.

### `GET /v1/sessions/{session_id}` <Status level="implemented" />

Session status

Session status. Needs the caller's signed read credential; 401 without one.

### `GET /v1/sessions/{session_id}/proposal` <Status level="implemented" />

Get the recommended proposal and its alternatives

The proposal to choose from. Signed read.

### `POST /v1/sessions/{session_id}/commitment` <Status level="implemented" />

Prepare the draft Commitment for signing

Prepares the Commitment to sign. The body is the caller's envelope.

### `POST /v1/sessions/{session_id}/authorize` <Status level="implemented" />

Authorize the proposal and start execution

Authorizes and runs the work. Blocks for as long as the delivery takes — do not set a short client timeout.

### `POST /v1/sessions/{session_id}/cancel` <Status level="implemented" />

Cancel the session

Cancels a non-terminal session.

### `GET /v1/sessions/{session_id}/result` <Status level="implemented" />

Delivered result

The delivered result. Signed read.

### `GET /v1/sessions/{session_id}/receipt` <Status level="implemented" />

Final receipt

The receipt. Signed read. The settlement figure is an accounting record and moves no value — see the coordination group.

### `GET /v1/sessions/{session_id}/events` <Status level="implemented" />

Session events (polling snapshot — NOT a push stream)

A polling snapshot, not a push stream. The name is SSE-shaped; the behaviour is polling, and the module says so itself.

### `POST /v1/objects` <Status level="implemented" />

Upload an input object

Uploads an input object, forwarding the caller's signed envelope.

### `POST /v1/runtimes` <Status level="implemented" />

Register an executable runtime package

Registers a runtime package, forwarding the caller's signed envelope.
