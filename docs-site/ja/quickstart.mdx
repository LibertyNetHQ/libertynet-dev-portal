## 3. 身元を自分で検証する

ここが LibertyNet が他と違うところで、2 分かける価値があります。

LibertyNet の DID は**自己証明的**です。識別子が公開鍵から導出されているため、SHA-256 さえあれば、ディレクトリを引かず、認証局に尋ねず、受け取ったレスポンスを信用することもなく、その主張を自分で確認できます。

`verify.py` として保存して実行してください。**インストールするものはありません。**

```python verify.py
import hashlib, json, re, urllib.request

B58 = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz"

def b58decode(s):
    n = 0
    for c in s:
        i = B58.find(c)
        if i < 0:
            return None
        n = n * 58 + i
    raw = n.to_bytes((n.bit_length() + 7) // 8, "big")
    # base58 は先頭のゼロバイトを落とすため、先頭の '1' 1 つにつき 1 バイト戻す
    return b"\0" * (len(s) - len(s.lstrip("1"))) + raw

# レジストリは /nodes では hex、/peers では base58 で鍵を返す。同じ鍵。
def key_bytes(pk):
    if re.fullmatch(r"[0-9a-f]{64}", pk):
        return bytes.fromhex(pk)
    return b58decode(pk)

def verify_id_binding(did: str, public_key: str) -> bool:
    """この DID は本当にこの公開鍵から導出されているか？"""
    key = key_bytes(public_key)
    if not key or len(key) != 32:
        return False

    digest = hashlib.sha256(key).hexdigest()
    body = re.sub(r"^did:svrp:(?:[a-z]:)?", "", did)

    if len(body) == 64:
        return body == key.hex()        # 完全 hex 形式
    if len(body) == 8:
        return body == digest[:8]       # 短縮形式
    if len(body) == 10:
        return body == digest[:10]      # 衝突時のフォールバック形式
    return False

with urllib.request.urlopen("https://registry.libertynet.ai/nodes", timeout=10) as r:
    nodes = json.load(r)["nodes"]

verified = sum(verify_id_binding(n["did"], n["public_key"]) for n in nodes)
print(f"{verified}/{len(nodes)} 件の身元を検証しました")
```

```text 実際の実行結果、2026-07-31
27/27 件の身元を検証しました
```

誰の許可も求めずに、このネットワーク上のすべての身元を暗号学的に確認しました。**それがこの設計の要点です。**

<Note>
**なぜ DID の表記が 2 つあるのか。** 同じ鍵が、短縮形 `did:svrp:n:<8桁hex>`（公開鍵の SHA-256 を切り詰めたもの）と完全形 `did:svrp:<64桁hex>`（公開鍵そのもの）の 2 通りで現れます。バインディングには短縮形が保存され、稼働中のデーモンは完全形を announce します。**同じノードです。** ここで文字列比較をすると 1 つのノードが 2 つに割れます。
</Note>

## 4. ノードを呼び出し、本当に応答したか確かめる

身元の検証で分かるのは DID と公開鍵が一致することだけです。誰かが応答できる状態にあることも、応答した相手が秘密鍵を持っていることも**証明しません**。この手順はその両方を確かめます。

<Warning>
**ネットワーク上のほとんどのノードは、あなたからは呼び出せません。**

多くの登録はプライベート IP や運用者にしか意味のないローカル名を広告しています。本人には本物でも、外からは到達できません。実際に使えるものをレジストリに直接尋ねてください:

```bash
curl -s 'https://registry.libertynet.ai/nodes?callable=1'
```

返ってくるのは**公開到達可能で登録署名を持つ**ノードだけです。今日その数は多くありませんが、SDK の既定もまさにこの集合です。
</Warning>

**nonce はあなたが決めます。** これが応答を「録音」ではなく「証明」にします。あらかじめ用意された内容への署名は、そのまま再生できてしまいます。

```python act.py
import json, urllib.request, secrets

def post(url, data):
    req = urllib.request.Request(url, data=json.dumps(data).encode(),
                                 headers={"content-type": "application/json"}, method="POST")
    with urllib.request.urlopen(req, timeout=15) as r:
        return json.load(r)

with urllib.request.urlopen("https://registry.libertynet.ai/nodes?callable=1") as r:
    node = json.load(r)["nodes"][0]

nonce = secrets.token_hex(8)
reply = post(node["endpoint"] + "/echo", {"nonce": nonce})

assert reply["nonce"] == nonce
assert reply["public_key"] == node["public_key"]

print("called   ", node["endpoint"])
print("signature", reply["signature"][:32], "…")
```

次に署名を検証します。Ed25519 にはライブラリが要ります。クイックスタートで何かをインストールするのはここだけです:

```bash
pip install cryptography
```

```python verify_reply.py
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

Ed25519PublicKey.from_public_bytes(key_bytes(reply["public_key"])).verify(
    b58decode(reply["signature"]),
    reply["signed_bytes"].encode(),
)
print("ok")
```

これが通れば、そのノードは先ほど検証した身元の秘密鍵を実際に保持しています。

## 5. SDK なら 1 行

上でやったことは、SDK が代わりにやってくれることです。しかも検証は無効化できません。

```python
from libertynet import LibertyNet

ln = LibertyNet()                  # 検証は既定で有効、無効化不可
nodes = ln.discovery.online()      # 検証済みかつ新しいノードのみ

for n in nodes:
    print(n.did, n.region, ",".join(n.capabilities))
```

`online()` は身元検証に失敗したレコードを拒否し、長く応答のないノードを除外します。**この検証を切るフラグはありません** — 未検証の身元を信用するクライアントを出荷するつもりはないからです。
