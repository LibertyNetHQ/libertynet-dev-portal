네 단계. 첫 단계는 `curl`만 있으면 되고, 나머지는 Node.js **또는** Python만 있으면 됩니다. **설치할 패키지는 없습니다.** 이 페이지의 모든 코드는 공개 전에 실제 네트워크에서 실행했으며, 표시된 출력은 실제 결과입니다.

<Info>
**가입 단계가 없습니다.** LibertyNet의 디스커버리는 공개되어 있습니다. 키를 기다리는 것이 아니라 애초에 키가 없습니다. 네트워크를 읽기 위해 키를 신청하라는 페이지가 있다면 그 페이지가 틀린 것입니다.
</Info>

**이 네트워크에서 가장 흔한 첫 실수입니다.**
</Warning>

## 3. 신원을 직접 검증하기

LibertyNet이 다른 점이 바로 여기이고, 2분을 쓸 값어치가 있습니다.

LibertyNet의 DID는 **자체 증명형**입니다. 식별자가 공개키에서 파생되므로, SHA-256 하나만 있으면 디렉터리 조회 없이, 인증 기관에 묻지 않고, 방금 받은 응답을 믿지 않고도 그 주장을 직접 확인할 수 있습니다.

`verify.py`로 저장하고 실행하세요. **설치할 것이 없습니다.**

```python verify.py
import hashlib, json, re, urllib.request

B58 = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz"

def b58decode(s):
    n = 0
    for c in s:
        i = B58.find(c)
        if i < 0:
            return None
        n = n * 58 + i
    raw = n.to_bytes((n.bit_length() + 7) // 8, "big")
    # base58은 선행 0바이트를 버리므로 선행 '1' 하나당 1바이트 복원
    return b"\0" * (len(s) - len(s.lstrip("1"))) + raw

# 레지스트리는 /nodes에서는 hex, /peers에서는 base58로 키를 제공. 같은 키.
def key_bytes(pk):
    if re.fullmatch(r"[0-9a-f]{64}", pk):
        return bytes.fromhex(pk)
    return b58decode(pk)

def verify_id_binding(did: str, public_key: str) -> bool:
    """이 DID가 정말 이 공개키에서 파생되었는가?"""
    key = key_bytes(public_key)
    if not key or len(key) != 32:
        return False

    digest = hashlib.sha256(key).hexdigest()
    body = re.sub(r"^did:svrp:(?:[a-z]:)?", "", did)

    if len(body) == 64:
        return body == key.hex()        # 전체 hex 형식
    if len(body) == 8:
        return body == digest[:8]       # 축약 형식
    if len(body) == 10:
        return body == digest[:10]      # 충돌 대비 형식
    return False

with urllib.request.urlopen("https://registry.libertynet.ai/nodes", timeout=10) as r:
    nodes = json.load(r)["nodes"]

verified = sum(verify_id_binding(n["did"], n["public_key"]) for n in nodes)
print(f"{verified}/{len(nodes)}개 신원 검증 완료")
```

```text 실제 실행 결과, 2026-07-31
27/27개 신원 검증 완료
```

누구의 허락도 구하지 않고 이 네트워크의 모든 신원을 암호학적으로 확인했습니다. **그것이 이 설계의 핵심입니다.**

<Note>
**DID 표기가 왜 두 가지인가.** 같은 키가 축약형 `did:svrp:n:<8자리hex>`(공개키 SHA-256의 앞부분)과 전체형 `did:svrp:<64자리hex>`(공개키 자체)로 나타납니다. 바인딩에는 축약형이 저장되고, 실행 중인 데몬은 전체형을 알립니다. **같은 노드입니다.** 여기서 문자열 비교를 하면 노드 하나가 둘로 쪼개집니다.
</Note>

## 4. 노드를 호출하고, 실제로 응답했는지 확인하기

신원 검증은 DID와 공개키가 일치한다는 것만 증명합니다. 누군가 응답할 수 있는 상태인지도, 응답한 쪽이 개인키를 가졌는지도 **증명하지 않습니다**. 이 단계는 둘 다 확인합니다.

<Warning>
**네트워크의 대부분 노드는 당신이 호출할 수 없습니다.**

많은 레코드가 사설 IP나 운영자에게만 의미 있는 로컬 이름을 광고합니다. 본인에게는 진짜지만 외부에서는 닿을 수 없습니다. 실제로 사용할 수 있는 것을 레지스트리에 직접 물어보세요:

```bash
curl -s 'https://registry.libertynet.ai/nodes?callable=1'
```

**공개적으로 도달 가능하고 등록 서명을 가진** 노드만 반환됩니다. 오늘 그 수는 적지만, SDK의 기본값도 정확히 이 집합입니다.
</Warning>

**nonce는 당신이 정합니다.** 그래야 응답이 '녹음'이 아니라 '증명'이 됩니다. 미리 준비된 내용에 대한 서명은 그대로 재생될 수 있습니다.

```python act.py
import json, urllib.request, secrets

def post(url, data):
    req = urllib.request.Request(url, data=json.dumps(data).encode(),
                                 headers={"content-type": "application/json"}, method="POST")
    with urllib.request.urlopen(req, timeout=15) as r:
        return json.load(r)

with urllib.request.urlopen("https://registry.libertynet.ai/nodes?callable=1") as r:
    node = json.load(r)["nodes"][0]

nonce = secrets.token_hex(8)
reply = post(node["endpoint"] + "/echo", {"nonce": nonce})

assert reply["nonce"] == nonce
assert reply["public_key"] == node["public_key"]

print("called   ", node["endpoint"])
print("signature", reply["signature"][:32], "…")
```

이제 그 서명을 검증합니다. Ed25519에는 라이브러리가 필요합니다 — 퀵스타트에서 무언가를 설치하는 유일한 단계입니다:

```bash
pip install cryptography
```

```python verify_reply.py
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

Ed25519PublicKey.from_public_bytes(key_bytes(reply["public_key"])).verify(
    b58decode(reply["signature"]),
    reply["signed_bytes"].encode(),
)
print("ok")
```

통과하면 그 노드는 방금 검증한 신원의 개인키를 실제로 보유하고 있는 것입니다.

## 5. SDK로는 한 줄

위에서 한 일이 SDK가 대신 해주는 일이며, 검증은 끌 수 없습니다.

```python
from libertynet import LibertyNet

ln = LibertyNet()                  # 검증 기본 활성화, 비활성화 불가
nodes = ln.discovery.online()      # 검증되고 최근에 확인된 노드만

for n in nodes:
    print(n.did, n.region, ",".join(n.capabilities))
```

`online()`은 신원 검증에 실패한 레코드를 거부하고 오래 응답이 없는 노드를 제외합니다. **이 검사를 끄는 플래그는 없습니다** — 검증되지 않은 신원을 신뢰하는 클라이언트는 출시할 생각이 없기 때문입니다.
